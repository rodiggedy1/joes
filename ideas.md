# Design Reference

## Ground-Truth Specification

The user supplied the complete HTML, CSS, and JavaScript implementation for **Joe’s Home Services — Book with AI Demo**. This reference is the chosen and authoritative design direction. The React build must preserve its off-white page frame, dark charcoal typography, lime call-to-action accent, editorially spacious two-column hero, outlined service cards, embedded AI request panel, floating assistant widget, and booking modal. Fidelity to the supplied code overrides any alternative visual direction.

## Design Philosophy

The experience is a **soft utility editorial** landing page: a residential-services brand expressed through calm paper-toned surfaces, practical information hierarchy, restrained green-lime accenting, generous whitespace, and direct booking-oriented microcopy. Interactive behaviors should be faithful and concise: users can select sample requests, open or close the assistant, send a simulated request, scroll to services, and open the dedicated booking dialog.

## Style Decisions

Typography combines a neutral system sans-serif with strong, tight headline tracking. The visual rhythm uses thin warm-gray rules, rounded rectangular containment, modest low-contrast shadows, and a single high-visibility lime accent. No generated imagery, alternate brand mark, or newly invented content will be introduced because the supplied reference contains neither and exact-code fidelity is required.
